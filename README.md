📌 Overview

The system replaces paper-based clinic processes with a secure digital platform for administrators, healthcare providers, and students.

✨ Features

Administrator

Secure login

Manage users

Manage appointments

View reports

Send notifications

Healthcare Provider

View appointments

Record diagnoses and treatments

Update medical records

Manage prescriptions

Student

Book appointments

View appointment history

Access medical records

Receive notifications

Submit feedback

🚀 Getting Started

Clone the repository.

git clone https://github.com/hitman1c/Clinic-Management-System-For-Botho-University.git

Open the project in Visual Studio.

Import BothoUniversityClinic.sql into MySQL.

Update the database connection string.

Build and run the application.
